C++ and Raylib

January 2, 2026

I have been learning C++ for about a year now. I started by reading almost the entirety of learncpp.com, and then I began developing some small games using Raylib, and it was great fun. At least until I hit the CMake “wall”.

I have since read Minimal CMake and Modern CMake for C++. CMake makes sense now, and I have come to enjoy it.

With these skills I am now developing a simple card game with C++ and Raylib, as well as Dear Imgui and catch2.

I started development in the usual OOP style, but after watching “Object-Oriented Programming is Bad” I switched to a procedural approach, just as an experiment. So far, it has been working out for me.

I’ll post a link to the source code on GitHub later.
