A card game written in C++ with Raylib

I have always loved TCGs, so I thought I would try to program one as a hobby project to practice C++.

It is built on top of the Raylib library, uses CMake as its build system and Catch2 for testing. I also added Dear Imgui as a quick way to create a debug UI.

So far the hardest part of the project really has been CMake. But after countless articles, YouTube tutorials and two whole books read on the subject, I managed to write a fairly clean and simple CMakeLists.txt system that keeps all dependencies neatly separated and modular.

I use Linux as my development environment and I have not tested this code on Windows yet. It should run on any system, since CMake is supposed to make things cross-platform, but if it doesn’t please don’t hesitate to e-mail me.

How to Play

  • Objective: Try to end up with the card with the highest stat.
  • At the start of the game, draw cards until you have 3 in your hand.
  • Draw a card at the beginning of every turn, by clicking the deck button.
  • Play a Unit card by dragging it into the center area, then play Action cards on subsequent turns to boost its stats.
  • You can only play 1 card per turn.
  • If both you and the CPU pass the turn without playing anything,
  • then your Units “Battle” and the player whose card had the highest stat wins.
